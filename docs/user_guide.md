system overview:

Gym Management system user guide 

It is designed to help with day to day gym operations. It helps admin, trainers and members to interact with a shared database. 

User roles and capabilities:

Admin - Full administrative access to oversee operations. 

View complete user directory and contact details.
Remove user accounts from the database.
Review annual membership revenue metrics.
Manage merchandise catalog (item pricing, inventory
quantities, and total inventory valuation).
Create and remove workout classes.

Trainer - Instructinal staff interface. 

Schedule and create new workout classes.
View self-assigned class schedules.
Browse and purchase gym memberships.
Browse available merchandise catalog.

Member - Standard user interface. 

Browse all available workout classes across all trainers.
Select and purchase gym memberships.
Browse available merchandise.
View personal lifetime transaction totals.

Common Workflows

Purchasing a membership: 
1. Launch the application and select **2. Login**.
2. Enter your credentials.
3. From the role menu, select **Purchase a gym membership**.
4. Enter the desired membership tier name (e.g., 'gold' 'annual' 'pass').
5. Enter the purchase price.
6. A success message confirms the purchase, and the total is automatically updated in your account history.

Managing Classes
  *To Create a Class (Admin / Trainer):*
  1. Select *Create workout class* from the main menu.
  2. Enter the class title (Spinning 101).
  3. Enter the scheduled day and time (Mon 6:45pm)
  4. The system links the class directly to your instructor ID.
  (To View Classes - Member)
  1. Select *Browse all available Workout Classes*
  2. The console displays all active classes, times, and assigned trainers.

Handling Merchandise 
    *Too add and update stock* 
  1. Select *Add new merchandise items and set price* 
  2. Provide the item name, category, price, and initial stock quantity.
  3. Select *View merchandise stock & total valuation* to verify total inventory value.
  *To View Items (Member / Trainer):*
  1. Select *View merchandise merchandise available for purchase*
  2. The system lists all in stock items with pricing.

System Limitations:

Console Interface: All interactions are text based via the terminal.

Manual Payment Processing: Payments are logged directly without real time credit card gateway processing.

Session Persistence: Exiting the program logs out the current user; returning requires reauthenticating.
